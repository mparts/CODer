# AI Log

In every case mentioned in this log, my involvement was direct. I was actively authoring and reviewing every output. What changes across situations is the level of my involvement, e.g. the report's appendix or certain one-off scripts, received less attention than e.g. the preprocessing did. So the security clearance each step received heavily depended on its use and its impact on the rest of the code or the study in general.

## Conclusion

Concluding, AI was actively used in the development of this project. What this use achieved is that secondary objectives were outsourced to AI, so I could use my time on the Primary ones. An example of this distinction is: Secondary would be the script itself for putting results in a table, or in a figure, and Primary would be analysing the actual table/figure, that the script produced. Generally speaking, a good summary of everything would be that the design, models, training and analysis are mine. AI wrote the tooling around them, and basically the more a script contributed to my research, the more closely I checked it.
